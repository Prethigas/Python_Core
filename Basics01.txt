Variables:
The two main types are Global Variables and Local Variables, with an additional special case called Nonlocal Variables.
1. Global Variables
Defined outside of all functions or classes.
Accessible throughout the program (inside and outside functions).
To modify a global variable inside a function, you must use the global keyword.
Example:
# Global variable
x = 10  
def modify_global():
    global x  # Declare that we are using the global variable
    x = x + 5
    print("Inside function:", x)
modify_global()
print("Outside function:", x)
Output:
Inside function: 15
Outside function: 15

2. Local Variables
Defined inside a function and accessible only within that function.
Created when the function starts and destroyed when the function ends.
They shadow global variables with the same name inside the function.
Example:
x = 10  # Global variable
def local_example():
    x = 5  # Local variable (shadows global x)
    print("Inside function:", x)
local_example()
print("Outside function:", x)
Output:
Inside function: 5
Outside function: 10

3. Nonlocal Variables (Special Case)
Used in nested functions to refer to variables from the enclosing function’s scope (not global).
Declared with the nonlocal keyword.
Example:
def outer():
    y = 10  # Enclosing function variable
    def inner():
        nonlocal y
        y += 5
        print("Inside inner:", y)
    inner()
    print("Inside outer:", y)
outer()
Output:
Inside inner: 15
Inside outer: 15
